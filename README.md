# Crypto Toolkit

Crypto Toolkit is a modern desktop application built with Python and CustomTkinter that provides a collection of useful cryptography tools in a clean and user-friendly interface.

## Features

* Live Hash Generation
* File Hashing
* HMAC Generator
* Encryption & Decryption
* Password Generator
* Hash Comparison
* Copy & Paste Support
* Dark and Light Mode
* Smooth Status Animations

## Built With

* Python
* CustomTkinter
* PyInstaller
* hashlib
* hmac

## Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Crypto-Toolkit.git
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python main.py
```

## Build the Executable

```bash
pyinstaller --onefile --windowed --icon=favicon.ico --name="Crypto Toolkit" main.py
```
